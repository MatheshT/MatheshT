# OWASP Top 10 Vulnerability Assessment Methodology

**Author:** Mathesh T

## Assessment Vectors
1. Broken Access Control (IDOR, privilege escalation)
2. Cryptographic Failures (weak hashing, cleartext transmission)
3. Injection (SQLi, NoSQLi, Command Injection)
4. Insecure Design & Threat Modeling
5. Security Misconfiguration (default credentials, open directory listing)
