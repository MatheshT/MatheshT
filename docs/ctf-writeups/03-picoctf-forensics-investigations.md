# PicoCTF Forensics & PCAP Network Traffic Analysis

**Author:** Mathesh T

## Key Investigation Techniques
1. Extracting binary payloads transmitted over raw ICMP echo requests (DNS/ICMP data exfiltration).
2. Reconstructing TCP streams and carving embedded files using `foremost` and Wireshark export objects.
3. Analyzing USB HID keystroke packet streams to recover typed passwords.
